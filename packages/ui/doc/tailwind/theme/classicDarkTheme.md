# classicDarkTheme.ts

## classicDarkTheme.ts 的职责

Classic dark theme CSS variables (`CLASSIC_DARK_THEME_CSS_VARS`): the previous default dark look retained as an optional preset (Manrope, richer shade steps, visible gradients).

## classicDarkTheme Example

```ts
import { CLASSIC_DARK_THEME_CSS_VARS } from "@orderly.network/ui";
```
